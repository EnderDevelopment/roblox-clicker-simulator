# Roblox Clicker Quest

This project is a simple clicker game for Roblox, designed to provide an engaging and interactive experience for players. It features a user-friendly interface with a clickable button and a score counter, making it easy for players to track their progress. The game is built using Roblox's Lua scripting language and utilizes Roblox's built-in services such as ReplicatedStorage and Players to manage the game state and player interactions.

## Install

1. Open Roblox Studio.
2. Create a new place or open an existing one.
3. Navigate to the `StarterPlayerScripts` folder in the Explorer.
4. Create a new script and name it `ClickerGame.client.lua`.
5. Copy the contents of `ClickerGame.client.lua` from this project into the script.
6. Navigate to the `ServerScriptService` folder in the Explorer.
7. Create a new script and name it `ClickerGame.server.lua`.
8. Copy the contents of `ClickerGame.server.lua` from this project into the script.

## Use

1. Launch the Roblox game in Roblox Studio.
2. Click the "Click Me!" button to increase your score.
3. Your score will be displayed on the screen.
